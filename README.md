# Portafolio Personal – Deyton Riascos Ortiz

Este es mi portafolio personal, donde presento mi experiencia, habilidades y proyectos destacados en desarrollo de software, automatización, inteligencia artificial y herramientas para desarrolladores.

## Características

- **Página de inicio**: Presentación personal y habilidades principales.
- **Sobre mí**: Experiencia laboral, educación y perfil profesional.
- **Proyectos**: Muestra de mis proyectos organizados por categorías (IA, automatización, dotfiles, aplicaciones).
- **Contacto**: Información para colaboración y redes profesionales.
- **Diseño moderno**: Interfaz limpia, responsiva y con soporte para modo claro/oscuro.

## Tecnologías utilizadas

- HTML5, CSS3 (Flexbox, Grid)
- JavaScript (vanilla)
- GitLab Pages / GitHub Pages para despliegue
